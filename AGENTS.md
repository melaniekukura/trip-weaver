# AGENTS.md

  ## Project overview
  Trip-Weaver is a React application for planning trips. It uses Firecrawl to gather information on flights, events, sights, safety, weather, etc. from the internet; AgentMail to send trip information to the user and gather information from newsletters; Convex for the back-end operations; and a Codex agent chat to help the user plan their trip.

  ## Commands
  - Run tests with `npm test`.
  - Run lint with `npm run lint`.
